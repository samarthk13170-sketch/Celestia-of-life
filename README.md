# Constellations of Life

An interactive star map that turns a year of "digital-life receipts" — songs played, movies watched, places visited, purchases, photos, messages, searches, events, and notes — into a galaxy. Individual activities become **stars**; meaningful groups of them become **constellations**, each one a narrated chapter of the year.

![Star map overview](public/data/manifest.json)

## The idea

Every row in a dataset is one moment in time. Instead of a boring table, each moment is placed in a spiral-galaxy layout:

- **Time** unwinds the spiral outward across the year (January near the core, December at the rim).
- **Activity type** determines which spiral arm a star sits in (music, movies, places, …).
- **Intensity** (play count, spend, duration, …) sets each star's brightness and size.

When you connect the dots, real patterns in the data surface as constellations with their own stories.

## Features

- **Canvas star field** with smooth zoom, pan, drag, twinkle animation, and a subtle parallax nebula.
- **Constellations** computed from the data — recurring late-night habits, seasonal streaks, travel clusters, favorite artists, and binge weekends.
- **Narrative sidebar** ("Chapters") that reads like a story of the year. Select a chapter to draw its constellation lines on the map.
- **Star inspector** — click any star to see what it was, when it happened, and which chapters it belongs to (related stars light up).
- **Search** stars by name and **filter** by activity type.
- Fully responsive: the insights panel becomes a slide-in drawer on mobile.

## Data

Datasets live in `public/data/*.csv` (one file per activity type) with a shared schema:

| column      | meaning                                  |
| ----------- | ---------------------------------------- |
| `type`      | activity category                        |
| `label`     | human-readable name of the moment        |
| `timestamp` | ISO datetime                             |
| `value`     | intensity (plays, spend, minutes, count) |

`public/data/manifest.json` lists which datasets to load. The sample data is synthetic and generated by `scripts/generate-data.mjs`, which deliberately embeds the patterns the constellations detect. Regenerate it with:

```bash
node scripts/generate-data.mjs
```

To use your own data, drop CSVs with the same columns into `public/data/` and update the manifest — no code changes needed.

## Architecture

- `lib/types.ts` — shared types, star-type list, and per-type color/label metadata.
- `lib/data.ts` — fetches and parses the CSVs (Papaparse), and computes each star's deterministic galaxy position.
- `lib/constellations.ts` — pattern-detection logic that groups stars into narrated constellations.
- `components/star-map.tsx` — the interactive Canvas renderer.
- `components/sidebar.tsx` — narrative chapters and the star inspector.
- `components/controls.tsx` — search and type filters.
- `app/page.tsx` — loads data with SWR and wires everything together.

## Tech

Next.js (App Router), TypeScript, HTML Canvas, Tailwind CSS, Papaparse, SWR.
